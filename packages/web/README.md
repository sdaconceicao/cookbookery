# Cookbookery

## Details

A web based recipe directory. Built with React

## Dev Requires

1. [Node 24](https://nodejs.org/en/download/)

## Setup

From the repository root:

1. `npm install`
2. `npm run bootstrap`

## Startup

1. npm start - API backend
2. npm run start:mocks - Mock backend

## Testing

npm run test:watch

## Build

npm run build
